
<h1>Kodi xStream Addon</h1>
<p>Aufgrund dümmster Gründe wurde am 25.07.2025 die xStream Repository offline genommen.</p>
<p>Hier ist somit die letzte und aktuellste Version, welche Ich von meinem Kodi Addons Ordner kopiert habe.</p>
<hr>
<h2>Branches</h2>
Es gibt 2 Branches in dieser GitHub Repository:

- **addon**: Das eigentliche Addon für Kodi

- **repository**: Die ursprüngliche ZIP-File, welche durch Kodi heruntergeladen wurde und die xStream Repository installiert, worüber ebenfalls die Updates bezogen wurden

<hr>
<h2>Installation</h2>
Wie man sich sicher denken kann ist es nun etwas komplizierter dieses Addon zum "Laufen" zu bringen ...

... aber auch das soll uns nicht hindern!


1. Lade die .ZIP Datei herunter
2. Öffne das Kodi Installationsverzeichnis
3. Entpacke die .ZIP Datei in den Ordner "addons"
4. Starte Kodi und aktiviere das Addon (sollte automatisch eine Meldung erscheinen)
<h3>Installationsverzeichnis</h3>

**Windows:** %AppData%\Kodi

**Linux:** ~/.kodi/  
`(Oft: /home/<DeinUsername>/.kodi/)`
